# Atelier Forma

Site vitrine d'Atelier Forma, atelier d'architecture intérieure et de rénovation.

## Lancer le site

Ouvrir `index.html` dans un navigateur, ou démarrer un serveur HTTP local depuis ce dossier :

```powershell
python -m http.server 8000
```

Le site est statique et ne nécessite aucune dépendance à installer.

## Contenu

- `index.html` : structure des pages et contenu.
- `styles.css` : styles et mise en page responsive.
- `script.js` : interactions et animations.
- `assets/` : vidéos, images et favicon.
